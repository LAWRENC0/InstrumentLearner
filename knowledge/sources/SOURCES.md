# Knowledge base sources

Free, legally downloadable material for building and checking the music theory knowledge base. Every item is either openly licensed (Creative Commons, GNU FDL), in the public domain, or an open-access thesis or article hosted by its university.

- The PDFs live in the subfolders next to this file. They are kept out of git (see `.gitignore`), so this catalogue is the record of what should be here.
- **How the material is used:** the knowledge base is written in our own words. Sources are read, compared and cited, not copied. This matters for the NC (non-commercial) and ND (no-derivatives) licences below, which allow reading and citing but not redistributing modified copies.
- **Status:** `downloaded` means the file is in the folder. `manual` means the site blocks automated downloads, so it must be saved by hand (see the last section).

## Manual downloads

These sites block automated downloads (they need JavaScript, a cookie or a click-through). Open each link in your browser, download the PDF, and save it at the local path shown. Paths are relative to `knowledge/sources/`.

Highest value first:
1. **Toby Rush, Music Theory for Musicians and Normal People.** [tobyrush.com/theorypages](https://tobyrush.com/theorypages/) → "download all pages as a single PDF". Save as `general-open/toby-rush-music-theory.pdf`.
2. **Jazz Theory (MTC130).** The site's PDF export is broken. Read it at [open.maricopa.edu/mtc130](https://open.maricopa.edu/mtc130/), or use your browser's Print → Save as PDF on each module. Save as `jazz/jazz-theory-mtc130.pdf`.
3. **Peter Manuel, Evolution and Structure in Flamenco Harmony.** [Academic Commons](https://academiccommons.columbia.edu/doi/10.7916/D8902FFS). Save as `flamenco/flamenco-harmony-manuel.pdf`.
4. **Farinha, choro piano PhD.** [YorkSpace link](https://yorkspace.library.yorku.ca/xmlui/bitstream/10315/28209/2/Farinha_Maria_F_2014_PhD.pdf). Save as `brazilian/choro-piano-farinha-york.pdf`.
5. **Gava, the harmonic language of bossa nova.** [UNESP link](https://repositorio.unesp.br/bitstreams/59d58012-c3cb-496b-a727-49842e46e31f/download). Save as `brazilian/bossa-nova-harmonic-language-gava-unesp.pdf`.
6. **Hill, the conjunto piano in 1940s Cuba.** [SOAS](https://eprints.soas.ac.uk/29328). Save as `latin-afro-cuban/conjunto-piano-cuba-hill-soas.pdf`.
7. **Clave in salsa (UBC).** [UBC Open Collections](https://open.library.ubc.ca/collections/24/items/1.0228889). Save as `latin-afro-cuban/clave-in-salsa-ubc.pdf`.
8. **Jared Hall, the Grip System (jazz harmony, voicings).** Search the title at [scholarship.miami.edu](https://scholarship.miami.edu/). Save as `jazz/grip-system-jazz-harmony-miami.pdf`.
9. **Gospel piano, 21st century (Ole Miss).** Search the title at [egrove.olemiss.edu](https://egrove.olemiss.edu/). Save as `gospel/gospel-piano-21st-century-olemiss.pdf`.
10. **Comprehensive Musicianship (counterpoint chapter and aural supplement).** [UNI ScholarWorks](https://scholarworks.uni.edu/facbook/522). Save as `aural-skills/comprehensive-musicianship.pdf`.
11. **Bernardo Pinto, samba guitar method (Portuguese).** [unirio.br link](https://www.unirio.br/cla%3B/ivl/cursos/bernardopinto.pdf). The server cut the connection on every automated attempt; a browser may manage it. Save as `brazilian/samba-guitar-method-unirio-pt.pdf`.
